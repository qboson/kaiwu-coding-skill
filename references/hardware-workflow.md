# 真机流程补充

仅在用户要求真机结果且已有许可时采用。接口见 [CIM 模块](module_docs/enterprise/cim.md)，
精度处理见 [预处理模块](module_docs/enterprise/preprocess.md)。

- 提交前确认已有许可，避免 SDK 等待交互输入；需要初始化时从环境读取凭据并调用 `kaiwu.license.init`，不写入代码或日志。
- 核对目标设备的位宽与维度限额；参考自旋和拆分新增变量都计入维度。
  系数满足整数范围后使用 int64 数组传入，避免 int8 点积溢出；不能靠强制转整数处理小数精度。
- 精度转换保存比例与还原映射。缩放取整可能改变最优解；split 也需核验还原关系与维度，不能仅凭维度满足就宣称无损。
- `CIMOptimizer` 的 `interval` 单位是分钟；使用 `wait=False` 自行轮询时，`solve` 返回 None 表示尚未取得结果。
- 使用独立持久的 checkpoint 目录；续查保持矩阵、task_name 和缓存目录不变。
  远程状态不明时先核对任务，不改变任务名自动重投，避免重复消耗配额；等待遵守任务预算。
- 原始 ±1 样本先保存再解码，同时保存变量映射与精度变换信息。
  按主文恢复参考自旋、遍历候选并重算原业务约束与目标；本地结果不能冒充真机样本。
